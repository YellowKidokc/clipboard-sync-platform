# ClipSync AutoHotKey Setup

1. Install AutoHotKey v2.
2. Set `base` and optional `apiToken` in `clipsync-hotkeys.ahk` if your server requires auth.
3. Run `clipsync-hotkeys.ahk` and `tray-icon.ahk`.
4. Optional startup: place shortcuts in `%APPDATA%\\Microsoft\\Windows\\Start Menu\\Programs\\Startup`.
